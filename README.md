#  Statistical Quality Control and Exploratory Data Analysis Using JMP
## Project Overview

This project demonstrates the use of JMP for exploratory data analysis (EDA) and statistical quality control in a chemical manufacturing process.
The analysis focuses on identifying patterns, relationships, and potential sources of variation in manufacturing data using graphical and statistical methods.

## Objectives

The main objectives of this project are to:

- Explore manufacturing process variables
- Identify patterns and potential sources of variation
- Use graphical methods to understand the data
- Apply Pareto analysis to identify the most important causes
- Examine relationships among multiple variables
- Develop practical insights for statistical quality control

## Exploratory Data Analysis

The JMP analysis includes:

- Column switching and variable exploration
- Pareto plots
- Sorted bar charts
- Packed bar charts
- Data filtering
- Exploratory visualization

## Key Analysis

### Pareto Analysis

Pareto plots are used to identify the categories contributing most significantly to the observed outcomes.

The cumulative percentage curve helps identify the relatively small number of categories that account for a large proportion of the total effect.
